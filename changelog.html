Welcome to PassCraft Education! Live

v26.12.0 Released 25 November 2026

Pages

  • Generator: create memorable passwords from Adjective + Noun or Colour + Animal patterns, each ending with a number and a symbol, or passphrases of 3 to 6 words with a choice of separator and an optional number and symbol. Includes a copy button, a session-only history and printable password slips.
  • Bulk Passwords: for ICT staff and technicians. Choose a .csv or .xlsx file with a column titled Password and fill it with a different generated password for each person. Pick a pattern style, a 4-word passphrase or 12 random characters, preview the result and download a new file named like “Year 9 accounts with Passwords 2026-11-25”. The file is read in your browser and never uploaded.
  • Strength Indicator: test an example password in your browser and get a checklist, an estimated time to crack and plain-English feedback. It looks for common passwords, dictionary words, keyboard patterns, sequences, repeats, years and look-alike character swaps.
  • Breach Check (optional): find out whether a password has appeared in a known data breach, using Have I Been Pwned. Nothing happens until you tick the consent box and click Check, and you are asked again every time. Only the first 5 characters of a scrambled version are sent, never the password.
  • Learn: six short, practical password habits: make it long, avoid commonly guessed passwords, one password per account, keep it secret, use a password manager and turn on MFA. Includes a “reuse domino” demo that shows how one leaked password can open other accounts, and a “Which is stronger?” quiz that picks five rounds at random from ten pairs of made-up example passwords. Both run in the browser and nothing is stored or sent.
  • MIT License page: a dedicated page alongside LICENSE.txt, with a plain-English summary and a way back to the main site.
  • Changelog: this page.

Design and content

  • Navy & Slate colour scheme, designed to look professional and be comfortable to read.
  • A site navigation bar linking the Generator, Bulk Passwords, Strength Indicator, Breach Check and Learn pages.
  • Privacy Policy, Terms of Use and Disclaimer written to be clear and concise, with each page keeping its own job.
  • Passwords are picked with an unbiased random method, so every word and character is equally likely.
  • Printed password slips include a blank line for writing the account name by hand, and a reminder to destroy the slip securely.
  • A README that explains the project, its features and its structure.
  • Fonts (Nunito and Baloo 2) are hosted on the site itself, so pages make no request to Google Fonts.

Accessibility and installability

  • Keyboard-navigable tabs, visible focus styles, screen-reader announcements for results and support for reduced motion.
  • A web app manifest so the site can be installed like an app.
  • Favicons and app icons.
