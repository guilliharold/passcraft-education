Last updated: 25 November 2026

Educational use only

PassCraft teaches good password habits. It isn’t a security product or professional cybersecurity, IT or legal advice, and it doesn’t replace your school’s or organisation’s password rules.

No guarantee of security

No password is ever guaranteed to be safe. PassCraft’s passwords use word lists and a simple pattern so they’re easy to remember, which makes them weaker than long random ones. For important accounts like email or banking, use a password manager and turn on multi-factor authentication.

Strength results are estimates

The strength meter, checklist, feedback and “time to crack” are rough guides based on simplified assumptions. A “Strong” result doesn’t mean a password is safe, and a weak result doesn’t mean it has been exposed.

Breach Check results

The Breach Check relies on a service run by someone else, which may be slow, unavailable or change without notice. “Not found” doesn’t mean a password is safe, only that it isn’t in the breached passwords that service holds. “Found” means it has been exposed somewhere and shouldn’t be used. If a check can’t be completed, there is no result.

Bulk Passwords

Bulk Passwords uses the same word lists and patterns as the Generator, or random characters, so the same limits apply. The downloaded file holds every password in plain text. How it is shared, stored and deleted, and how student details are handled, is up to you and your school.

Your responsibility

Please don’t enter your real passwords into the Strength Indicator. Test an example similar in style instead. The optional Breach Check is the one exception, because it only works on a real password. It sends only part of a scrambled version, and only after you agree (see the Privacy Policy). Keep generated passwords secret, use each on one account only, and destroy printed slips when you no longer need them.
