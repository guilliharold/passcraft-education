Password Safety Tips
📏Make it long

Aim for twelve (12) or more characters. A few random, unrelated words get you there and are easy to remember. Avoid using song lyrics or phrases about you.

🚫Never use these

These are some of the most guessed passwords. Avoid them, and close variations too.

password qwerty 111111 iloveyou admin Aa123456 abc123 qwerty123
🔁One password per account

Websites do get hacked. If you reuse a password, attackers can try it on your other accounts. A different password for each one keeps a leak contained.

🤫Keep it secret

Never share it, not even with friends. Teachers and school IT will never ask for it. If a message pushes you to log in urgently, go to the site yourself instead of clicking its link. Only type a password into the real site or app it belongs to, or a tool you understand.

🗄️Use a password manager

An app that creates and remembers a different password for every account, locked behind one strong master password. PassCraft Education suggests Bitwarden. Please check with a parent or trusted adult before choosing a password manager.

📲Turn on MFA

Multi-factor authentication asks for a second proof, like a code from an app, so a stolen password isn't enough. Turn it on wherever it's offered, starting with your email.
